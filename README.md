# 🏦 Banking Customer & Risk Analytics with Machine Learning

A complete end-to-end banking analytics platform demonstrating Data Analyst skills —
from raw data through SQL analysis, Python EDA, customer segmentation, risk scoring,
and an interactive Streamlit dashboard with ML-powered risk prediction.

> **Note:** This project uses entirely **synthetic data** generated programmatically.
> No real customer data is used. It is intended purely for portfolio demonstration.

---

## 📋 Business Problem

Banks need to:
- Understand their customer base and risk exposure
- Identify high-risk customers before they default
- Reduce churn among high-value customers
- Monitor loan portfolio health and payment performance
- Make data-driven decisions backed by analytics

---

## 🎯 Objectives

1. Build a synthetic but statistically realistic banking customer dataset
2. Clean and process the data using a robust pipeline
3. Store data in SQLite and write meaningful SQL analyses
4. Perform comprehensive EDA with visualisations
5. Develop business KPIs and customer segments
6. Build an ML model to predict customer risk
7. Deploy a professional interactive Streamlit dashboard

---

## 📦 Dataset

| Property | Value |
|---|---|
| Records | 10,000 customers |
| Source | Synthetic (generated by `generate_data.py`) |
| Fields | 37 features |
| Target | `Risk_Label` (Low / Medium / High) |

### Key Features

| Feature | Description |
|---|---|
| Customer_ID | Unique customer identifier |
| Age, Gender | Demographics |
| State, City | Geographic location |
| Occupation | Employment type |
| Account_Type | Savings / Current / Salary / NRI |
| Account_Balance | Current account balance (₹) |
| Monthly_Income | Monthly income (₹) |
| Credit_Score | Credit score (300–900) |
| Loan_Amount | Outstanding loan amount (₹) |
| Debt_to_Income_Ratio | EMI / Monthly Income |
| Missed_Payments | Number of missed EMI payments |
| Late_Payments | Number of late payments |
| Churn_Status | 1 = churned, 0 = active |
| Default_Status | 1 = defaulted, 0 = not defaulted |
| Risk_Label | Low / Medium / High (target variable) |

**Risk is determined by:** credit score, DTI ratio, missed payments, default history,
loan burden, income level, late payments, and existing loan count.

## 🧹 Data Cleaning

Pipeline implemented in `src/data_processing.py`:

- Duplicate removal (by Customer_ID)
- Data type correction
- Missing value imputation (median for numeric fields)
- Age validation (18–100)
- Credit score validation (300–900)
- Categorical standardisation
- Date conversion and Days_Since_Transaction derivation
- DTI recalculation for consistency
- Outlier handling via clipping

## 👥 Customer Segmentation

Rule-based segments:

| Segment | Criteria |
|---|---|
| Premium | Balance ≥ ₹5L, Credit ≥ 750, Products ≥ 3 |
| High Value | Balance ≥ ₹2L, Credit ≥ 650 |
| Digital First | Online + Mobile banking active |
| Loan Dependent | Active loan with DTI > 0.35 |
| At Risk | Churned or inactive > 90 days |
| Low Engagement | < 5 transactions/month |
| Regular | All others |

## 🤖 Machine Learning

### Models Trained

| Model | Notes |
|---|---|
| Logistic Regression | Baseline, scaled features |
| Decision Tree | Interpretable, depth-limited |
| Random Forest | Ensemble, best performer |
| XGBoost | Optional, if installed |

### Pipeline

```
Raw Features → StandardScaler (LR only) → Classifier → Risk Label
```

### Evaluation Metrics
- ROC-AUC (primary selection metric)
- F1 Score (weighted)
- Precision & Recall
- Confusion Matrix
- ROC Curve per class

### Class Imbalance
Handled using `class_weight="balanced"` in all classifiers.

### Final Model
Saved to: `models/risk_model.pkl`
Metrics: `models/model_metrics.csv`

## 🚀 How to Run

### Step 1 — Generate data, build database, train models

```bash
python generate_data.py
```

This will:
- Generate 10,000 synthetic customer records
- Clean and process the data
- Create the SQLite database
- Train Logistic Regression, Decision Tree, and Random Forest
- Save the best model as `models/risk_model.pkl`
- Save model metrics as `models/model_metrics.csv`

### Step 2 — Launch the dashboard

```bash
python -m streamlit run app.py
```

Open your browser at: **http://localhost:8501**
